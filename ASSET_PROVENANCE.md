# Rune Blocks — происхождение ассетов

Дата фиксации: 2026-09-20.

- Все PNG в `public/` созданы специально для Rune Blocks в ходе разработки проекта. Пользовательские референсы использовались только как направление и не включены в сборку.
- `public/audio/moonlit-isles.wav` — оригинальный процедурно созданный ambient-loop для Rune Blocks; интерфейсные эффекты синтезируются Web Audio во время игры.
- Иконка и обложка в `release/promo/` созданы для этой игры; скриншоты и оба MP4 записаны непосредственно из Rune Blocks.
- Внешние шрифты, фотостоки, сторонние музыкальные треки и сторонние игровые ассеты в runtime-сборке не используются.
- Права на использование и публикацию материалов в рамках пункта 3.5 подтверждены владельцем проекта в переписке.

Файл фиксирует происхождение материалов для проверки черновика; юридические оригиналы подтверждений следует хранить вместе с проектом.
